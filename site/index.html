Agent Pets

Every session of your coding agent gets its own pet on the taskbar. It codes at a desk, types commands, reads files, catches web pages with a butterfly net, waves when it needs you and naps when it's idle.

Every state

Read your agents from the corner of your eye.

The pose follows the session: what the hooks report becomes what the pet does. Pick a state, or let it play.

    On the taskbar

    Progress, context and limits sit right next to them.

    Limits at a glance

    5-hour and weekly bars for Claude, Codex and Antigravity, task progress under each pet, and a +N badge when the taskbar runs out of room. A pet that waits for you or hit an error always stays visible.

    Bubbles and subagents

    See the question an agent asks or the command it runs. Subagents show up as mini pets next to their parent after five seconds of work.

    One click back to the session

    1. a deep link into the Claude or Codex app,
    2. the window the session runs in,
    3. a new terminal that resumes it,
    4. the resume command, copied for you.

    Notifications that know when to speak

    A toast when an agent waits for you longer than 15 s, when a long turn finishes, when a limit passes 90% or will run out within the hour. Mute them until 8:00 from the tray.

    Your layout

    Next to the tray, on the left, anywhere you drag them, or in a floating window. Any monitor, any size. Ctrl+Alt+Shift+J jumps to the agent that needs you.

    Statistics, for fun

    A podium of your projects, token and time counters, an agent race, a 26-week activity calendar and badges, counted from the transcripts already on your disk.

    Inside Claude Code

    A mod for Claude Code, too.

    The app installs it for you. It's also in this repo's marketplace, for when you only want the mod.

    • Live limits. Your 5-hour and weekly limits with exact reset times after every turn, without reading your login.
    • /pets opens a pane with the sessions and limits of every agent.
    • Nudges when another agent needs you or fails.
    • A pixel Clawd with a status line above the prompt.

    The door

    Any agent can knock.

    An agent without its own integration still gets a pet: send its state with hook.exe report or one HTTP call to 127.0.0.1. Type a name and see who answers.

    Turn the door on in Settings → Apps. All fields and the HTTP version →

    Privacy

    Your sessions stay on your computer.

    States come from local hooks and files. Only titles, progress and counters are kept, never message content. The app listens only on 127.0.0.1, behind a random token.

    Every connection it makes to the internet

    1. github.comThe update check reads latest.json from the releases. Nothing is sent, and you can turn it off. Updates install only with a valid signature.
    2. api.anthropic.comOnly if you allow it: your Claude plan limits, with the login Claude Code keeps. Off by default; the mod doesn't need it.

    Never: prompts, answers, tool results, file contents.

    Light, too. Drawing pauses under full-screen apps, slows to 10 fps on battery, and drops to 20, 10 or 4 fps when nothing moves.

      Install

      Three steps to a livelier taskbar.

      1. Download and run

        Agent.Pets_0.17.0_x64-setup.exe. Installers are built on GitHub Actions; code signing is being set up, so until then SmartScreen may ask: More info → Run anyway.

      2. Let the wizard connect your agents

        It finds them, installs the hooks, and lets you pick notifications, autostart and a look.

      3. Restart open sessions

        So they pick up the hooks. Change anything later in Settings; uninstalling also removes the hooks.
