# Contributing

Thanks for wanting to help. Bug reports, ideas and pull requests are all welcome.

## Before you open a pull request

- Open an issue first for anything bigger than a small fix, so we can agree on the approach.
- Run the tests: `cargo test --workspace` and `pnpm --dir app test`.
- Keep changes focused. One feature or fix per pull request.
- Write code, comments and user-facing text in English. Polish UI strings go in `app/src/i18n/pl.ts`.

See [docs/building.md](docs/building.md) for the setup.
