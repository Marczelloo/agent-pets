# 0.11: sprawdzenia (Copilot, Antigravity, zużycie opencode)

## Automatyczne

Bramka: `cargo test --workspace` i `pnpm --dir app test --testTimeout=30000`, obie zielone na gałęzi `v0.11`.

| Obszar | Czym sprawdzone |
|---|---|
| Stare dane | `settings.json` z 0.10 bez `copilot`/`antigravity` (oba wyłączone), sesja z 0.10 bez `usage`, nadpisania wyglądu nowych agentów po zapisie |
| Trasy | `/v1/events/{copilot,antigravity}`: 404 przy wyłączonej integracji, 204 po włączeniu w locie, 401 zły token, 400 zła koperta |
| `hook.exe --agent/--event` | koperta z nazwą zdarzenia; Antigravity `Stop` → `{"decision":"stop"}`, inne → `{}`; Copilot nic; wyjście także bez widżetu i przy złym wejściu, < 1 s; zła nazwa zdarzenia albo agenta → nic nie wysłane |
| Copilot | każde zdarzenie z nagranej ręcznie sesji (fixture), oba zapisy pól, program z koperty, pytanie przy `elicitation_dialog`, `permission_prompt` bez zmiany stanu (JetBrains wysyła go przy każdym narzędziu), ciche powiadomienia i błędy do odzyskania, podagent jako dziecko, niebezpieczne id, test prywatności (`SEKRET-123` w prompcie, wyniku, treści pliku, odpowiedzi podagenta i ścieżce transkryptu) |
| Antigravity | każde zdarzenie z fixture'a, model, akcje (`view_file`, `run_command`, `replace_file_content`), `Stop` z błędem i bez `fullyIdle`, mapa narzędzi, test prywatności (`CodeContent`, ścieżki transkryptu i artefaktów) |
| Integracje | komendy dla cmd/bash i PowerShella ze spacją i apostrofem w ścieżce; Copilot: zapis, powtórny zapis bez zmian, usunięcie, cudzy plik nietknięty, brak `~/.copilot`; Antigravity: dopisanie obok cudzego hooka z kopią, zły JSON, tablica, cudzy klucz `agent-pets`, usunięcie tylko naszego klucza, usunięcie pustego pliku, brak `~/.gemini`, tworzenie `config/` |
| Baza opencode | suma pięciu kolumn tokenów, „dziś” od lokalnej północy (odpowiedź minutę przed nie wchodzi), konto (`openai`/`anthropic` przy koszcie 0), brak pliku, stara schema, zablokowana baza (< 1 s), każde zapytanie tylko z tabel `session`/`message`/`part` i dozwolonych pól; lokalna północ z czasem letnim |
| Zużycie w runtime | tokeny sesji i konto na zwierzaku, suma dnia, wyłączenie opencode czyści sumę; baza otwierana tylko przy włączonym opencode i żywym zwierzaku, od razu i potem co 30 s |
| Statystyki | pozycje `opencode:<id>` z projektem, podagentem, tokenami (wyjście + rozumowanie), pytaniami (`question`), narzędziami i czasem pracy; ponowny skan bez zmian = 0, zmiana sesji = przeliczenie bez podwójnego liczenia; pauza; opencode w wyścigu i na podium |
| UI | karta opencode: linia zużycia (z kosztem i bez), paski konta tylko z danymi; przełączniki i opisy Copilota i Antigravity; opencode w statystykach (nazwa, zwierzak, wygląd) |
| Wygląd | Copilot (brązowy skórzany hełm, niebieskie gogle, jasne oczy nad linią ramion, widoczne przy biurku) i Antigravity (łuk z otworem, kolory Google, lewitacja bez nóg) w każdym stylu, ruchu i scenie bez NaN; Pixel i Sticker rysują je jak Clean |

## Na żywo (z użytkownikiem)

- [ ] Wygląd Copilota i Antigravity zaakceptowany na podglądzie (`looks-dev?cast=new`).
- [ ] Copilot w IntelliJ: włączenie, stany, prośba o zgodę z dymkiem, podpis „· JetBrains”, skok do okna. Nagrane koperty → `crates/pets-core/tests/fixtures/copilot/live-*.jsonl` (teksty jako `…`) z testem.
- [ ] Antigravity po aktualizacji: stany, model w tooltipie; `{}` przy `PreToolUse` nie zmienia pytań o zgodę; `Stop` kończy pracę normalnie; powłoka uruchamia komendę z `hook_command`. Nagrane koperty → `fixtures/antigravity/live-*.jsonl`.
- [ ] Antigravity: przyjmuje nasz wpis (bez pola `enabled`), a inne hooki użytkownika dalej działają; czy `PreInvocation` przychodzi raz na turę czy na każde wywołanie modelu (to drugie psułoby czas tury i powiadomienie o długiej turze); czy podagenci wołają hooki z własnym `conversationId` (wtedy byliby osobnymi pełnymi zwierzakami).
- [ ] opencode: tokeny sesji i dnia zgodne z bazą, paski Codexa przy dostawcy `openai`, opencode w statystykach.
