# 0.11 — wyniki sprawdzeń (2026-09-27)

Tylko odczyt: dokumentacja producentów i lokalne katalogi użytkownika (same struktury, bez plików z tokenami). Nic nie było uruchamiane ani zmieniane w konfiguracji agentów.

## S1: Copilot

- **Hooki:** dokumentacja „GitHub Copilot hooks reference” (docs.github.com). Pliki `version: 1` z mapą `hooks`, komendy `type: command` z kluczami `bash`, `powershell` albo `command`, `timeoutSec` (domyślnie 30).
- **Katalogi:**
  - CLI: `.github/hooks/*.json` w repo, `~/.copilot/hooks/*.json` użytkownika, `~/.copilot/settings.json`, pluginy;
  - VS Code: te same katalogi (`~/.copilot/hooks`), a pliki Claude'a tylko przy `chat.useClaudeHooks` (domyślnie wyłączone);
  - JetBrains: w 03.2026 tylko `.github/hooks` w repo. Od 06.2026 plugin przechodzi na Copilot CLI jako domyślny harness agenta. U użytkownika `~/.copilot/logs` pokazuje „Starting CLI in server mode (stdio)”, czyli harness CLI już działa. Czy wtedy czytane są hooki użytkownika, trzeba sprawdzić na żywo.
- **Zdarzenia:** `sessionStart`, `sessionEnd`, `userPromptSubmitted`, `preToolUse`, `postToolUse`, `postToolUseFailure`, `agentStop`, `subagentStart`, `subagentStop`, `errorOccurred`, `preCompact`, `notification` (typy `permission_prompt`, `elicitation_dialog`, `agent_idle`, `agent_completed`…), `permissionRequest`.
  - Zapis PascalCase (`SessionStart`, `PreToolUse`, `Stop`) daje pola snake_case zgodne z Claude'em (`session_id`, `tool_name`, `tool_input`);
  - zapis camelCase daje `sessionId`, `toolName`, `toolArgs`.
- **Model:** żadne zdarzenie go nie wymienia.
- **Wyjście:** kod 0 i pusty wynik to brak zdania. Kod 2 przy `preToolUse` to odmowa. Przekroczony czas nie blokuje (fail-open).
- **U użytkownika:** plugin `copilot-intellij` 1.5.61, ostatnie sesje agenta 05.2026. Copilot CLI nie jest na `PATH`, VS Code niezainstalowany.

## S2: Antigravity

- **Hooki:** dokumentacja antigravity.google/docs/hooks. Plik `~/.gemini/config/hooks.json` (globalnie; IDE, aplikacja 2.0 i CLI) albo `.agents/hooks.json` w projekcie. Mapa „nazwa → zdarzenia”, pole `enabled`, komendy `type: command`, `timeout` (domyślnie 30).
- **Zdarzenia (tylko pięć):**
  - `PreToolUse` (`toolCall.name`, `toolCall.args`, `stepIdx`);
  - `PostToolUse` (plus `error`);
  - `PreInvocation` i `PostInvocation` (`invocationNum`);
  - `Stop` (`terminationReason`, `error`, `fullyIdle`).
- **Wspólne pola:** `conversationId`, `workspacePaths`, `transcriptPath`, `artifactDirectoryPath`, `modelName`.
- **Czego brakuje:** startu sesji, promptu, prośby o zgodę i powiązania podagenta z rodzicem.
- **Wyjście:**
  - `PreToolUse` może zwrócić `decision`;
  - `Stop` wymaga `decision`: `continue` wznawia agenta, każda inna wartość pozwala skończyć.
  - Zachowanie `{}` przy `PreToolUse` sprawdzimy na żywo.
- **U użytkownika:** Antigravity w `D:\Programy\Antigravity`, `package.json` 1.107.0, IDE 1.18.3, plik z 2026-02-19. W plikach programu nie ma śladu `PreInvocation` ani `hooks.json`, czyli jest to wersja sprzed hooków (I/O 2026). Dane rozmów w `~/.gemini/antigravity/conversations/*.pb` (protobuf) nie są potrzebne.

## S3: baza opencode

- **Plik:** `~/.local/share/opencode/opencode.db`, SQLite w WAL (migracje drizzle).
- **Tabela `session`:** `cost`, `tokens_input`, `tokens_output`, `tokens_reasoning`, `tokens_cache_read`, `tokens_cache_write`, `model` (JSON `{id, providerID, variant}`), `agent`, `directory`, `parent_id`, `time_created`, `time_updated`.
- **Tabela `message`:** `data` jako JSON, dla `assistant` z polami `providerID`, `modelID`, `cost`, `tokens {input, output, reasoning, cache {read, write}}`, `time {created, completed}`, `path {cwd, root}`.
- **Tabela `part`:** `data` z `type` (m.in. `tool`) i `tool`.
- **W tej samej bazie są tokeny logowania:** `credential`, `account`, `control_account`, `session_share.secret`. Odczyt musi ograniczać się do `session`, `message`, `part` i wybranych pól (spec 0.11 §4.1).
- **U użytkownika:** 143 sesje, 6719 wiadomości. Wszystkie koszty 0 (subskrypcje). Dostawcy odpowiedzi: `zai-coding-plan` 2932, `openai` 2273, `opencode` 875, pozostali pojedynczo. Kopia bazy użyta do odczytu została od razu usunięta.
