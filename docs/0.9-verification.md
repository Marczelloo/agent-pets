`pets-cli stats-scan --out <plik tymczasowy>` na maszynie użytkownika (Windows 11, bez gry na pełnym ekranie), do osobnej księgi, bez dotykania `~/.agent-pets/stats.json`.

| Pomiar | Wynik |
|---|---|
| Historia | 248 plików, ok. 2650 MB (Claude Code ok. 410 MB, Codex ok. 2,2 GB) |
| Czas pełnego skanu | 7,2 s (skan w jednym wątku, bez przerw) |
| Czas procesora | 7,1 s |
| Szczytowa pamięć procesu | 46 MB (nie rośnie z rozmiarem pliku: czytanie linia po linii) |

| Drugi przebieg bez zmian w plikach | 0,05 s |

W aplikacji skan idzie wolniej z założenia: wątek o niskim priorytecie, porcje po 4 MB z przerwą 20 ms, pauza przy grze na pełnym ekranie.

Sumy (bez nazw projektów): ok. 7,3 mld tokenów, z czego 97% to odczyt z cache, 211 h pracy agentów, 140 pytań.

Pierwszy pomiar dał 8,5 mld tokenów i 194 pytania: przegląd gałęzi wykazał, że Claude Code dopisuje starsze odpowiedzi jeszcze raz (wznowienie, kompaktowanie) i te powtórki liczyły się drugi raz (ok. 1,24 mld tokenów, ok. 1/3 wywołań narzędzi). Poprawione zbiorem już policzonych `message.id` w kursorze pliku.
