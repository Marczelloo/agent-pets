# 0.12: sprawdzenia (Cursor, Grok Build, ZCode)

## Automatyczne

Bramka: `cargo test --workspace` i `pnpm --dir app test --testTimeout=30000`, obie zielone na gałęzi `v0.12`.

| Obszar | Czym sprawdzone |
|---|---|
| Stare dane | `settings.json` z 0.11 bez `cursor`/`grok`/`zcode` (wszystkie wyłączone); wygląd i nadpisania nowych agentów po zapisie |
| Trasy | `/v1/events/{cursor,grok,zcode}` otwierają się i zamykają z przełącznikiem; zdarzenie przy wyłączonej integracji nie tworzy zwierzaka; zdarzenia należą do swoich agentów |
| `hook.exe --agent/--event` | Cursor: koperta z nazwą zdarzenia, zawsze odpowiedź pozwalająca iść dalej (`{"continue":true}` przy `beforeSubmitPrompt`, `{}` przy reszcie), także bez widżetu i przy złym wejściu; Grok i ZCode: koperta, brak wyjścia; id sesji Groka z `GROK_SESSION_ID`; zła nazwa zdarzenia → nic nie wysłane; ogromny prompt Cursora nie wychodzi z hooka |
| Obcy wywołujący | `caller`: Grok po `GROK_HOOK_EVENT` (także z JSON-em Cursora), Cursor po `cursor_version`, ZCode po `ZCODE_SESSION_ID` z `hookEventName`; hook Claude'a wywołany przez innego agenta nic nie wysyła; Claude uruchomiony z terminala ZCode dalej jest Claude'em |
| Cursor | każde zdarzenie z fixture'a, agent/proces/folder/model, id z `conversation_id` albo `session_id` i `safe_id`, tura przerwana, przerwana przez `aborted` i z błędem, podagent jako dziecko rozmowy, mapa narzędzi i teksty akcji, test prywatności (prompt, e-mail, załączniki, treść pliku) |
| Grok Build | każde zdarzenie z fixture'a, oba zapisy pól, tylko powiadomienia czekające na człowieka dają „czeka na Ciebie”, złe id i nieznane zdarzenie → nic, test prywatności (prompt, odpowiedź, wynik narzędzia), id sesji ze środowiska |
| ZCode | każde zdarzenie z fixture'a, `PermissionRequest` pyta o akcję i nigdy nie pokazuje `reason`, oba zapisy pól, złe id i nieznane zdarzenie → nic, test prywatności (prompt, wynik narzędzia) |
| Integracje | wykrycie po folderach; Cursor: jeden wpis na zdarzenie przy powtórnym włączeniu, dopisanie obok cudzych hooków z kopią, nietypowy plik nietknięty, bez `~/.cursor` odmowa, plik utworzony przez nas znika po wyłączeniu; Grok: zapis i usunięcie własnego pliku, cudzy `agent-pets.json` nietknięty; ZCode: wpisy w `hooks.events` i `hooks.enabled: true` (schemat z bundla ZCode), jawne `enabled: false` → odmowa bez zmian, `enabled` znika po wyłączeniu, jeśli nie było go w kopii, zdarzenie wprost w `hooks` → odmowa, dopisanie do konfiguracji bez ruszania reszty, zły JSON nietknięty, tworzenie `cli/`, pusty klucz `hooks` znika, ścieżka z `ZCODE_DATA_BASE_DIR`; odinstalowanie usuwa hooki wszystkich trzech |
| UI | przełączniki Cursor, Grok Build i ZCode z opisem i plakietką „eksperymentalne”, dopiski o braku „czeka na Ciebie” (Cursor) i stanu błędu (ZCode); kreator nie włącza eksperymentalnych agentów sam; `appFor` dla trzech |

## Na żywo (z użytkownikiem)

Jedna maszyna (Windows 11), zainstalowany podpisany build 0.12.0. Koperty nagrane na czas testu obok naszego hooka (tylko nazwy zmiennych środowiska; nagrywarka, nagrania i kopie usunięte po teście).

- [x] Wygląd Cursora, Groka i ZCode zaakceptowany na podglądzie; ręka Groka pod brodą obraca się z głową przy myśleniu.
- [x] Cursor 3.22: działa `~/.cursor/hooks.json`, komenda idzie przez `pwsh` (BOM na wejściu, poprawione), stany i nazwy narzędzi, podpis „· Cursor”. Poprawione po nagraniu: folder z `workspace_roots` (puste `cwd`), `stop` z `aborted` i spóźnione `postToolUseFailure` nie otwierają tury, rozmowa `draft-…` nie tworzy zwierzaka. Nagranie: `tests/fixtures/cursor/live-3.22.jsonl`. Nie sprawdzone: pytania o zgodę po `{}` i skok do okna.
- [x] Grok Build: plik w `~/.grok/hooks` działa po restarcie Groka, `GROK_HOOK_EVENT` i `GROK_SESSION_ID` są, `Notification` `idle_prompt` słusznie pomijane. Poprawione: przerwana tura (`StopCancelled`) kończy turę. Nie widziane na żywo: zdarzenia narzędzi i pytania o zgodę.
- [x] ZCode: `hookEventName`, `ZCODE_SESSION_ID`, oba zapisy pól, proces `ZCode.exe`; aplikacja nie nadpisuje naszych wpisów. Poprawione: schemat `hooks.events` + `hooks.enabled` (wcześniejszy kształt ZCode odrzucał w całości). Nie widziane na żywo: zdarzenia narzędzi i `PermissionRequest`.
- [x] Regresja: Claude Code, Codex i opencode jak w 0.11 (potwierdzone na żywo, 0.12.0).

Wszystkie trzy zostają *eksperymentalne*: po jednej sesji na jednej wersji każdego agenta, bez zdarzeń narzędzi Groka i ZCode na żywo.
