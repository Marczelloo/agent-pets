# Agent Pets 0.10.0 (więcej agentów: fundament + opencode). Plan implementacji

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Cel:** otworzyć model na kolejnych agentów i programy, dodać furtkę dla dowolnych narzędzi, uniwersalnego zwierzaka, model w tekście i pierwszego nowego agenta: opencode z własną maskotką.

**Architektura:**
- **Rdzeń:**
  - nowe warianty `Agent`, `Source`, `App`;
  - pola `model`, `agent_name`, `app_name`, `host_pid`;
  - moduł `host` (drzewo procesów → program);
  - moduł `adapters` (opencode, generic);
  - dwie nowe trasy endpointu;
  - integracja opencode (plik pluginu).
- **hook.exe:** program‑gospodarz w kopercie hooka Claude'a i podkomenda `report` (furtka z linii poleceń).
- **Aplikacja:** skok do okna gospodarza, przełączniki opencode i furtki.
- **Front:**
  - podtytuł `agent · model · program` i ikonka programu w panelu;
  - skiny `opencode` i `blob`;
  - w stylach Pixel/Sticker nowe skiny rysowane jak w Clean.

**Stos:** jak w 0.9 (Tauri 2, React/TS, vitest, Rust workspace).

**Specyfikacja:** `docs/superpowers/specs/2026-09-27-agent-pets-more-agents-design.md` (wiąże). Spike'i: `docs/0.10-spikes.md`.

## Global Constraints

- **Z wcześniejszych wersji obowiązuje:**
  - TDD;
  - teksty w UI tylko przez JSX albo `textContent`;
  - skan i18n (brak polskich literałów poza `i18n/pl.ts`);
  - `settings.json` i zapisane sesje z 0.9.1 muszą się wczytać bez zmian (`#[serde(default)]` na każdym nowym polu).
- **Hook nigdy nie blokuje agenta:**
  - `hook.exe` i plugin opencode: limit łączenia 150 ms, całość 300 ms, zawsze kod 0 / brak wyjątku na zewnątrz, nic nie wypisują w trybie hooka;
  - wędrówka po procesach to jeden zrzut Toolhelp, najwyżej 8 poziomów.
- **Prywatność:**
  - adaptery nie przekazują treści promptów, odpowiedzi ani plików; tylko stan, rodzaj narzędzia, krótki tekst akcji, pytanie w `needs_you`, id modelu, nazwy programów;
  - tekst z furtki: przycięty, bez znaków sterujących, renderowany jako tekst.
- **Pliki agentów:** zmiany w konfiguracji opencode tylko przez integrację (za zgodą w kreatorze/ustawieniach), nasz plik oznaczony nagłówkiem, cudzego pliku o tej nazwie nie nadpisujemy.
- **Push i wydanie** tylko po zgodzie użytkownika; skan prywatnych danych i push w osobnych krokach.
- **Edycje skryptami:**
  - Python z pliku zapisanego narzędziem Write, bez `python -c` z backtickami;
  - backslashe tylko przez Write/Edit;
  - LF;
  - grep diffu pod kątem `uid=` i nazwy użytkownika przed commitem.
- **Build:** `CARGO_BUILD_JOBS=6`. Bez okien na ekranie i bez buildów release, gdy działa gra na pełnym ekranie (`SHQueryUserNotificationState` ≠ 5).
- **Bramka testów:** `cargo test --workspace` i `pnpm --dir app test --testTimeout=30000`, oba z kodem wyjścia.
