# Agent Pets 0.11.0 (Copilot, Antigravity, zużycie opencode). Plan implementacji

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Cel:** zwierzaki dla GitHub Copilota i Antigravity (hooki → `hook.exe`) oraz zużycie opencode z jego bazy: tokeny na karcie w panelu (A), opencode w statystykach (B), paski konta Claude'a albo Codexa na karcie opencode (C).

**Architektura:**
- **Rdzeń:**
  - `Source`/`SubKind` dla Copilota i Antigravity;
  - `adapters::{copilot, antigravity}` (koperta → zdarzenia);
  - `AgentEnvelope`;
  - bramki tras (`Doors`);
  - integracje: własny plik hooków Copilota i klucz w `hooks.json` Antigravity;
  - `opencode_db` za cechą `opencode-db` (rusqlite, tylko do odczytu);
  - zużycie w sklepie i w snapshocie;
  - `stats::opencode`.
- **hook.exe:** tryb `--agent <id> --event <nazwa>` z wyjściem wymaganym przez Antigravity.
- **Aplikacja:**
  - przełączniki;
  - naprawa przy starcie;
  - `hook.exe` na miejscu;
  - skan statystyk opencode;
  - snapshot z `agent_usage`.
- **Front:**
  - karta opencode (linia zużycia, paski konta);
  - opencode w statystykach;
  - skiny `copilot` i `antigravity` z lewitacją.

**Stos:** jak w 0.10 (Tauri 2, React/TS, vitest, Rust workspace); nowa zależność `rusqlite` (`bundled`) tylko w cesze `opencode-db` rdzenia, włączanej przez aplikację.

**Specyfikacja:** `docs/superpowers/specs/2026-09-27-agent-pets-0.11-design.md` (wiąże). Rozpoznanie: `docs/0.11-spikes.md`.

## Global Constraints

- **Z wcześniejszych wersji obowiązuje:**
  - TDD;
  - teksty w UI tylko przez JSX albo `textContent`;
  - skan i18n (brak polskich literałów poza `i18n/pl.ts`);
  - `settings.json` i zapisane sesje z 0.10 wczytują się bez zmian (`#[serde(default)]` na każdym nowym polu; TS: nowe pola opcjonalne).
- **Hook nigdy nie blokuje agenta:**
  - limit łączenia 150 ms, całość 300 ms;
  - zawsze kod 0;
  - wyjście tylko takie, jakiego wymaga agent (Copilot: nic; Antigravity: `{}`, przy `Stop` `{"decision":"stop"}`);
  - wyjście wypisane także wtedy, gdy widżet nie działa.
- **Nigdy nie zmieniamy decyzji agentów:**
  - żadnych pól zgody w odpowiedzi;
  - nigdy `continue` przy `Stop` Antigravity.
- **Prywatność:**
  - adaptery przekazują tylko stan, rodzaj narzędzia, krótki tekst akcji z białej listy argumentów, pytanie przy `needs_you`, id modelu i program;
  - nigdy prompt, `toolResult`, `response`, ścieżka transkryptu.
- **Baza opencode:**
  - tylko do odczytu, tylko tabele `session`, `message`, `part`;
  - z `data` tylko `json_extract` z listy ze spec §4.1;
  - nigdy `auth.json` ani tabele z tokenami;
  - bez włączonej integracji opencode nie otwieramy bazy.
- **Pliki agentów:** tylko przez integracje (zgoda w kreatorze/ustawieniach).
  - Copilot: nasz plik `~/.copilot/hooks/agent-pets.json`, cudzego o tej nazwie nie nadpisujemy.
  - Antigravity: tylko klucz `agent-pets` w `~/.gemini/config/hooks.json`, przez `hooks_install::edit_file` (kopia `hooks.json.agent-pets.bak` obok pliku, zapis atomowy, zły JSON = błąd bez zapisu).
  - **Ruling planu wobec spec §3.3:** kopia obok pliku, jak dla Claude'a, zamiast `~/.agent-pets/backup/`. Ten sam sprawdzony mechanizm; koszt pomyłki: inna lokalizacja kopii.
- **Sieć:** tylko 127.0.0.1 (bez nowych połączeń).
- **Push i wydanie** tylko po zgodzie użytkownika; skan prywatnych danych i push w osobnych krokach.
- **Edycje skryptami:**
  - Python z pliku zapisanego narzędziem Write;
  - backslashe tylko przez Write/Edit;
  - LF;
  - grep diffu pod kątem `uid=` i nazwy użytkownika przed commitem.
- **Build:** `CARGO_BUILD_JOBS=6`. Bez okien i bez buildów release przy grze na pełnym ekranie (`SHQueryUserNotificationState` ≠ 5).
- **Bramka testów:** `cargo test --workspace` i `pnpm --dir app test --testTimeout=30000`, oba z kodem wyjścia. Cecha `opencode-db` włącza się w bramce przez unifikację cech (aplikacja jest członkiem workspace'u); `hook.exe` budowany osobno (`build-hook.mjs`, `-p pets-hook`) jej nie ma.

```rust
// adapters/mod.rs
#[derive(Serialize, Deserialize, Clone, Debug, PartialEq)]
pub struct AgentEnvelope {
    pub ts: i64,
    pub ppid: Option<u32>,
    /// nazwa zdarzenia z argumentu `--event` (Antigravity nie przysyła jej w JSON-ie)
    pub event: String,
    pub payload: serde_json::Value,
    #[serde(default)]
    pub host: Option<crate::host::Host>,
}
/// Zdarzenia początku tury, przy których hook.exe liczy program (jeden zrzut procesów).
pub fn host_event(agent: &str, event: &str) -> bool {
    matches!((agent, event), ("copilot", "SessionStart" | "UserPromptSubmit") | ("antigravity", "PreInvocation"))
}
// adapters/antigravity.rs
/// Odpowiedź dla Antigravity: `Stop` wymaga decyzji; cokolwiek innego niż `continue` pozwala skończyć.
pub fn reply(event: &str) -> &'static str { if event == "Stop" { r#"{"decision":"stop"}"# } else { "{}" } }
```
