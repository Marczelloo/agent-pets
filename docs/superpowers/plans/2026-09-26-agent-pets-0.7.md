# Agent Pets 0.7.0 (auto-updater, ręczne usuwanie, ustawienia paska). Plan implementacji

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Cel:** trzy rzeczy w wersji 0.7.0:
- aplikacja sama sprawdza, pobiera i instaluje nowe wersje;
- użytkownik ukrywa zwierzaki i sesje ręcznie;
- scenę w pasku da się ustawić: pozycja, monitor, tło, rozmiar, odstępy, wyrównanie, kolejność, widoczne elementy, tryb pływający.

**Architektura:**
- **Rdzeń (`pets-core`):**
  - nowe sekcje ustawień `stage` i `updates`;
  - czysta reguła ukrywania `dismiss`;
  - czysta brama „spokojny moment” `update_gate`.
- **Aplikacja (Rust):**
  - `updater.rs` na `tauri-plugin-updater`;
  - kanał poleceń do wątku rdzenia (usuwanie);
  - `shell/` z trybami pozycji, strefami paska, wyborem monitora, oknem pływającym, przeciąganiem i menu kontekstowym.
- **UI:**
  - układ sceny ze skalą, odstępami, kolejnością i tłem;
  - panel z ✕, „Usuń nieaktywne”, „Cofnij” i paskiem aktualizacji;
  - nowa karta „Pasek” oraz sekcja aktualizacji w karcie „Ogólne”.

**Stos:** jak w 0.6, plus `tauri-plugin-updater` 2 i `tauri-plugin-process` 2.

**Specyfikacja:** `docs/superpowers/specs/2026-09-26-agent-pets-0.7-design.md` (wiąże). Tło: `2026-09-24-agent-pets-design.md`.

## Global Constraints

- Wszystko z faz 2–6 obowiązuje:
  - testy przed commitem, stopka commita;
  - teksty tylko przez JSX albo `textContent`;
  - pliki współdzielone w `~/.agent-pets`;
  - okno pokazane przez Win32 chowane też przez Win32;
  - skan i18n bez polskich literałów poza `pl.ts`.
- **Sieć:** aplikacja łączy się wyłącznie z `127.0.0.1`, z `api.anthropic.com` (za zgodą) i z `github.com`, tylko dla `latest.json` i instalatora z wydań `Marczelloo/agent-pets`. Sieć obsługuje wyłącznie Rust.
- **Klucz podpisu:**
  - leży w `~/.tauri/agent-pets.key` i nie trafia do repo, logów ani wyjścia komend;
  - skrypty czytają go z pliku do zmiennej środowiskowej procesu;
  - treść klucza nigdy nie jest drukowana.
- **Push, tag i publikacja wydania** wymagają zgody użytkownika. Skan prywatnych danych i push to osobne kroki.
- **Gałąź `v0.7`:** nie przełączać gałęzi podczas działającego `pnpm tauri dev` użytkownika.
- **Pełny ekran:** nie przeszkadzać grze na pełnym ekranie. Ręczne testy okien i instalatora tylko, gdy użytkownik nie gra; w razie wątpliwości zapytać.
- **Zgodność:** plik ustawień z 0.6 musi dawać dokładnie dzisiejsze zachowanie.
- **i18n:** każdy nowy tekst jest w `pl.ts` i `en.ts`. Teksty z Rusta idą przez `tr(lang, pl, en)`.

## Review Focus

1. **Plik ustawień z 0.6** (bez `stage` i `updates`) albo z nieznaną wartością (`"position": "top"`): scena wygląda i działa jak w 0.6, a zapis nie gubi nieznanych pól. Test w tasku 1.
2. **Usunięta sesja, restart aplikacji, potem agent pyta o zgodę:** po restarcie sesja dalej jest ukryta; po `needs_you` wraca i dostaje toast. Testy w taskach 4 i 5.
3. **Tryb `auto`, gdy agent pracuje albo gra jest na pełnym ekranie:** instalacja czeka i rusza dopiero po 2 min spokoju. Każde przerwanie zeruje licznik. Test w tasku 2.
4. **Wybrany monitor odłączony:** scena wraca na główny, a ustawienie zostaje; po podłączeniu scena wraca na wybrany. Test w tasku 8.
5. **Pozycja `custom`, gdy przybywa ikon aplikacji:** scena jest dosuwana do krawędzi wolnej strefy i nigdy nie zasłania ikon. Test w tasku 7.

// pets-core::update_gate
pub const CALM_MS: i64 = 120_000;
/// Zajęty: sesja pracuje albo czeka na użytkownika, gra na pełnym ekranie, otwarty panel lub ustawienia.
pub fn busy(states: &[State], fullscreen: bool, ui_open: bool) -> bool {
    fullscreen || ui_open || states.iter().any(|s| matches!(s, State::Thinking | State::Working | State::Compacting | State::NeedsYou))
}
#[derive(Default)]
pub struct Calm { since: Option<i64> }
impl Calm {
    /// true, gdy od `CALM_MS` nieprzerwanie nie jest zajęty.
    pub fn observe(&mut self, busy: bool, now: i64) -> bool {
        if busy { self.since = None; return false; }
        now - *self.since.get_or_insert(now) >= CALM_MS
    }
}
